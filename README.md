smart-food-donation-system

An innovative Smart Food Donation System that helps reduce food waste by connecting food donors such as hotels, restaurants, and individuals with NGOs and people in need. The system supports efficient food sharing, donation tracking, and timely distribution using a simple and user-friendly application.

Features

- Add surplus food donations.
- Enter food name, meal quantity, and pickup location.
- Validate required form fields.
- Display submitted donations in the Available Donations section.
- Save donation records using browser Local Storage.
- Delete donation entries.
- Responsive design for different screen sizes.

Technologies Used

- HTML – Structure of the website.
- CSS – Styling and layout.
- JavaScript – Form validation and donation management.
- Local Storage – Save donation details in the browser.
- GitHub Pages – Host the website online.

Live Demo

"Smart Food Donation System" (https://madhumitha-ponnan2007.github.io/smart-food-donation-system/)

How to Use

1. Open the live website.
2. Enter the food name.
3. Enter the quantity of meals.
4. Enter the pickup location.
5. Click Donate Food.
6. View the donation in the Available Donations section.
7. Delete a donation entry when needed.

Project Objective

The main objective is to reduce food waste and encourage people to donate surplus food to those in need.

Current Limitation

Donation records are stored in the browser's Local Storage. They are not automatically shared with other users or devices.

Future Enhancements

- Add donor and NGO registration.
- Integrate a cloud database.
- Track donation collection status.
- Develop an admin dashboard.
- Enable notifications for new donations.

Conclusion

The Smart Food Donation System demonstrates how web technologies can be used to organize surplus food donations through a simple and user-friendly application.
